# CIJA — Centro de Integração Jovem Aprendiz

O CIJA é uma plataforma desenvolvida para conectar jovens aprendizes e empresas de maneira moderna, acessível e eficiente. O projeto foi criado com foco em experiência do usuário, autenticação segura e uma interface profissional totalmente responsiva.

A proposta da plataforma é simplificar o processo de cadastro, login e gerenciamento de acessos entre candidatos e empresas, oferecendo uma base sólida para futuras funcionalidades relacionadas a vagas, processos seletivos e gestão empresarial.

---

## Tecnologias Utilizadas

- React
- TypeScript
- Vite
- React Router DOM
- CSS Modules
- Supabase


---

## Funcionalidades

### Área do Jovem Aprendiz
- Cadastro completo
- Login autenticado
- Recuperação de senha
- Validação de CPF
- Validação de telefone
- Verificação de idade mínima
- Feedback visual em tempo real

### Área Empresarial
- Login empresarial separado
- Controle de acesso por autenticação
- Estrutura preparada para dashboard

### Sistema
- Integração com Supabase Auth
- Validações frontend e backend
- Animações de sucesso e erro
- Máscaras automáticas de campos
- Responsividade para dispositivos móveis
